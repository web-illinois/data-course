# Testing Access

[Back to Configuration Knowledge Base](README.md)

**Where:** Configuration > **Testing Access** (`/configuration/testing`)

The testing area is a separate (test) environment. You can either:
- **Temporarily give yourself access** to the testing area from this page, or
- Add yourself permanently as a user on the testing source's [Security](05-security.md) page.

This page is available even before a source is selected.
