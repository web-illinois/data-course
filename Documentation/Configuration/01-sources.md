# Sources

**Where:** Configuration > **Sources** (`/configuration/sources`)

A **source** is a separate workspace for a college, department, or unit. See the [Configuration overview](README.md) for the full definition.

> Changes in one source never affect any other source.

## Create a new source
1. Enter a **Source Name** (the display name).
2. Enter a **Source Code** (a short code; it prefixes the IDs of everything in the source).
3. Select **Create Source**.
4. Your selection changes to the new source automatically.

To switch to a different source later, go to the **home page** and choose it.

## Source Owners
Lists each source's owner with an email link. To request access to a source, email the owner shown.

## Tips
- Choose a clear, short code. It cannot be treated as a throwaway; it is part of every ID in the source.
- A new source starts blank. Next, set up [Fields Used](02-fields-used.md), [filters](03-manage-filters.md), and [security](05-security.md). You can also load configuration from a file into a blank source (see the Transfer documentation).
