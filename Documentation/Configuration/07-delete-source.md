# Delete Source

[Back to Configuration Knowledge Base](README.md)

**Where:** Configuration > **Delete Source** (`/configuration/deletion`)

> **These actions are automatic and cannot be undone.** Confirm the selected source before continuing. Deleting affects only this source, not others. Save a backup first using the Transfer pages.

## Delete Source Data
Deletes **all data** in the source, but keeps:
- Filters
- Instructions
- Security settings
- Logs

Use this to start fresh while keeping your configuration.

## Delete Source
Deletes the source data **and structure**: everything associated with the source.

Each action uses a delete notice that asks you to confirm.
