# Manage Filters

[Back to Configuration Knowledge Base](README.md)

**Where:** Configuration > **Manage Filters** (`/configuration/filters`)

Tags, departments, and skills are keywords configured **per source**. Editors toggle them on programs, credentials, and courses, and visitors use them to search.

> Filters belong to this source only. Changes do not affect other sources.

## Filter types
Choose a **Type**:
- **Departments**
- **Skills**
- **Course / Program Length**
- **Tags**

## Editing a list
For the selected type, the current filters are listed. Each can be:
- Edited (rename)
- Moved up or down to change order
- Removed

## Add a new filter
1. Enter a name under **Add New Filter**.
2. Select **Add**.
3. Select **Save** to store the list.

## Notes
- Editing pages (Program, Credential, Course Filters) show these filters as toggles. If no filters exist, they link here.
- Filters can also be saved and loaded through the Transfer pages. A Configuration load only works on a blank source.
- Removing a filter may remove it from items that use it. Check items after large changes.
