# Settings

[Back to Configuration Knowledge Base](README.md)

**Where:** Configuration > **Settings** (`/configuration/settings`)

Source-wide options. To control fields inside programs, credentials, courses, and so on, use [Fields Used](02-fields-used.md).

> Settings apply only to this source.

| Setting | What it does |
|---------|--------------|
| **Initiate Search** | When on, a search runs automatically when a list page opens. Turn off if you have many courses or credentials. |
| **Use OpenAI to Modify Information** | When on, OpenAI is used to auto-populate import information. |
| **Split Up Seminar Classes** | When on, sections with distinct titles and descriptions are split up. |
| **Base URL** | Used when your item URLs are relative paths, so the application can open and view your program. |

Select **Save** to apply.
