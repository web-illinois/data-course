# Course List

[Back to Credentials Knowledge Base](README.md)

**Where:** Credential sidebar > **Course List** (`/credential/courselist`)

To add courses to a credential you must add a **requirement set**. You can add an existing set or create a new one.

## Plan of Study Introduction
Enter introductory text for the plan of study, then save.

## Chosen Requirement Sets
Lists the requirement sets on this credential. Select a set's title to edit it.

## Add Requirement Sets
1. Search for a requirement set.
2. Select **Add to Credential** to attach an existing one.
3. Or select **Create New Requirement Set** to create a new private set for this credential.

Changes show "Credential saved successfully." when saved.

If your source uses programs, a **Back** button returns you to the program.
