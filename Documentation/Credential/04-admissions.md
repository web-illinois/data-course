# Admissions

[Back to Credentials Knowledge Base](README.md)

**Where:** Credential sidebar > **Admissions** (`/credential/admissions`)

## Fields (rich text)
| Field | What to enter |
|-------|---------------|
| **Admission Requirements** | What applicants need to be admitted. |
| **Transfer Student Requirements** | Requirements specific to transfer students. |
| **Program Tracks** | Tracks or concentrations. |

## Steps
1. Enter text in each editor.
2. Select **Save**.
3. Select **View Credential** to confirm.
