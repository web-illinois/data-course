# Related Links

[Back to Credentials Knowledge Base](README.md)

**Where:** Credential sidebar > **Related Links** (`/credential/relatedlinks`)

Build a list of related links that is displayed on the credential page.

1. Add links with the link list editor (link text and web address).
2. Remove or reorder as needed.
3. Select **Save**.

Instructions from your administrator appear under **Instructions**. If the page says Related Links are not used, enable them in **Configuration > Fields Used > Credentials**.
