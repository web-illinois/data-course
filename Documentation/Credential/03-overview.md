# Overview

[Back to Credentials Knowledge Base](README.md)

**Where:** Credential sidebar > **Overview** (`/credential/overview`)

## Fields
| Field | What to enter |
|-------|---------------|
| **Description** | Full description (rich text). |
| **Program Notes Title** | Heading for the notes below. |
| **Program Notes** | Additional notes (rich text). |
| **Who Should Apply** | Intended audience (rich text). |
| **Job Type Information** | Types of jobs graduates can pursue (rich text). |
| **Professional Information** | Licensure, accreditation, and similar details (rich text). |
| **Skills** | Skills students gain (rich text). |

## Steps
1. Enter text in each editor.
2. Select **Save**.
3. Select **View Credential** to check formatting.
