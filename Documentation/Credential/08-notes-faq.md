# List of Notes / FAQ

[Back to Credentials Knowledge Base](README.md)

**Where:** Credential sidebar > **List of Notes / FAQ** (`/credential/notelist`)

Generates an FAQ-like area or individual notes displayed on the credential page.

1. Add notes with the note list editor.
2. Reorder or remove notes as needed.
3. Select **Save**.

Instructions from your administrator appear under **Instructions**. Note templates can be defined in the Configuration section; to override a template on this credential, use a note with the same title as the template.

If the page says notes are not used, enable them in **Configuration > Fields Used > Credentials**.
