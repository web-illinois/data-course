# Quote Information

[Back to Credentials Knowledge Base](README.md)

**Where:** Credential sidebar > **Quote Information** (`/credential/quote`)

## Fields
| Field | What to enter |
|-------|---------------|
| **Quote Title** | Heading for the quote. |
| **Quote Subtitle** | Who said it. |
| **Quote** | The quote text. |
| **Quote Image** | Photo of the person. |
| **Quote Image Alternative Text** | Description of the photo for screen readers. |

## Steps
1. Fill in the fields and add the image.
2. Select **Save**.

Get permission before publishing a person's name and photo.
