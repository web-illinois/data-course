# Technical Information

[Back to Credentials Knowledge Base](README.md)

**Where:** Credential sidebar > **Technical Information** (`/credential/technical`)

- **Status on Site**: whether the credential is active on your site.
- **Internal Search Text**: text to help editors find the credential; not for display.
- Select **Save** after changing either.

## Information to Copy
- **Id**: the credential's unique ID.
- **Edit Link**: direct link to edit it.

## Transfer Credential To Another Program
Shown only if your source uses programs. The page shows the current program. To move the credential:
1. Search for the destination program.
2. Select **Transfer to This Program**.

> If this is the only credential in its program, moving it **deletes the program**.

## Delete
The delete notice at the bottom removes the credential. Deletion cannot be undone.
