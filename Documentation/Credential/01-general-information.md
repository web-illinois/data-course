# General Information

[Back to Credentials Knowledge Base](README.md)

**Where:** Credential sidebar > **General Information** (`/credential/general`)

## Fields
| Field | What to enter |
|-------|---------------|
| **Title** | The credential's name. |
| **Summary Title** | Heading shown in lists and search results. |
| **Summary Text** | Short description for lists and search results. |
| **Contact** | Name of the contact person. |
| **Contact Email** | The contact's email address. |
| **Credit Hours** | Total credit hours required. |
| **Cost** | Cost of the credential. |
| **Online Cost** | Cost if taken online. |
| **Credential Length** | Expected time to complete. |
| **Online Credential Length** | Expected time to complete online. |
| **Suggested Enrollment Date** | When students should enroll. |
| **Online Suggested Enrollment Date** | Enrollment date for online students. |
| **Suggested Enrollment Date Fall / Spring / Summer** | Enrollment dates for each term. |
| **Credential Type** | Selected from a list (for example, degree or certificate). |
| **Course Format** | Check every format that applies. |

## Steps
1. Fill in the fields.
2. Select **Save**.
3. Select **View Credential** to check the result.

Fields your source has hidden will not appear.
