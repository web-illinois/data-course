## Basics
- A **credential** is an individual certificate, endorsement, or degree. If your source uses programs, each credential belongs to a program, and a **Back** button returns you to it.
- Most pages have an orange **Save** button. Changes are not stored until you select it. The **Security** page is the exception.
- **View Credential** opens the published page.
- Fields can be hidden or given instructions in **Configuration > Fields Used > Credentials**.
