# Faculty

[Back to Sections Knowledge Base](README.md)

**Where:** Section sidebar > **Faculty** (`/section/faculty`)

## Faculty List
Each faculty member shows **Name**, **Net ID**, **Profile URL**, a **Show In Profile?** switch, and a **Remove** button. Edit values directly or select **Remove** to delete the entry.

## Add / Edit Faculty
1. Enter **Name**, **Net ID**, and **Profile URL**, and set **Show In Profile?**.
2. Select **Add**.
3. Select **Save** to store all changes.

Select **Back** to return to the Section List.
