# Technical Information

[Back to Sections Knowledge Base](README.md)

**Where:** Section sidebar > **Technical Information** (`/section/technical`)

- **URL Fragment**: the part of the web address that identifies the section. Select **Save** after changing it; changing it may break existing links.

## Information to Copy
- **Id**: the section's unique ID.
- **Edit Link**: direct link to edit the section.

## Delete
The delete notice at the bottom removes the section. Deletion cannot be undone. After deletion you are taken to the Courses page.

Select **Back** to return to the course's Section List.
