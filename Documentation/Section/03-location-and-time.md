# Location and Time

[Back to Sections Knowledge Base](README.md)

**Where:** Section sidebar > **Location & Time** (`/section/locationtime`)

| Group | Field | What to enter |
|-------|-------|---------------|
| **Location** | **Building** | Building name. |
| | **Room** | Room number. |
| **Time** | **Term** | The term (for example, Fall or Spring). |
| | **Semester Year** | The year of the term. |
| | **Begin Date** | First day of the section. |
| | **End Date** | Last day of the section. |
| | **Days** | Meeting days. |
| | **Time** | Meeting time. |

Select **Save** when finished, or **Back** to return to the Section List.
