# General Information

[Back to Sections Knowledge Base](README.md)

**Where:** Section sidebar > **General Information** (`/section/general`)

The page displays the section's **Title** (read only) at the top.

| Field | What to enter |
|-------|---------------|
| **Section Code** | The section's code. |
| **Alternate Title** | A title to use for this section instead of the course title. |
| **Alternate Description** | A description to use for this section instead of the course description. |
| **CRN** | The course reference number. |
| **Format Type** | How the section is delivered (for example, online or on-campus). |
| **Credit Hours** | Credit hours for the section. |

Select **Save**, or **Back** to return to the Section List.
