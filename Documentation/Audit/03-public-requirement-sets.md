# Public Requirement Sets

[Back to Audit Reports Knowledge Base](README.md)

**Where:** Audit > **Public Requirement Sets** (`/audit/publicrequirementsets`)

**Description:** Lists public (shared) requirement sets that are used by only one credential, which you may want to make private.

Requirement sets are either:
- **Public**: can be shared by multiple credentials.
- **Private**: can only be used by the credential assigned to it.

| Column | Meaning |
|--------|---------|
| **Title** | The requirement set. Select it to open it. |
| **Is Active** | Whether the set is active on your site. |

## What to do
Open the set, go to **Technical Information**, and turn off **Is This Shared?**. The toggle is only available when exactly one credential uses the set.
