# Recently Changed Items (Access Logs)

[Back to Audit Reports Knowledge Base](README.md)

**Where:** Audit > **Access Logs** (`/audit/changed`). The page heading is **Recently Changed Items**.

**Description:** Lists recent manual changes made to programs, credentials, courses, and other items in your source.

| Column | Meaning |
|--------|---------|
| **Date Changed** | When the change was saved. |
| **Title** | The item that was changed. |
| **Net ID** | Who made the change. |
| **Category Type** | The kind of item (for example, Program, Credential, or Course). |
| **Field Type** | Which page or group of fields was changed. |

## Notes
- Only manual edits in the application are listed. JSON loads and API updates are not included.
- For exact field-level details, contact IT Partners @ Education.
- To see the history of one item, use that item's **Audits and Changes** page.
