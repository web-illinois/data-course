# Unused Requirement Sets

[Back to Audit Reports Knowledge Base](README.md)

**Where:** Audit > **Unused Requirement Sets** (`/audit/unusedrequirementsets`)

**Description:** Lists requirement sets that are not used by any credential, so you can reuse or delete them.

| Column | Meaning |
|--------|---------|
| **Title** | The requirement set. Select it to open it. |
| **Is Active** | Whether the set is active on your site. |

## What to do
- Add the set to a credential from the credential's **Course List** page if it should be used.
- Delete it from its **Technical Information** page if it is no longer needed. Only sets that no credential uses can be deleted.
