# List of Requirement Sets

[Back to Audit Reports Knowledge Base](README.md)

**Where:** Audit > **List of Requirement Sets** (`/audit/listrequirementsets`). The page heading is **List of All Public Requirement Sets**.

**Description:** Lists every public requirement set with the courses it contains.

| Column | Meaning |
|--------|---------|
| **Title** | The requirement set, with its courses listed below it. Select the set or a course to open it. |
| **Is Active** | Whether the set is active on your site. |

Use this report to review the contents of shared requirement sets before changing them, since a change to a shared set affects every credential using it.
