# Fields Used: Programs

[Back to Fields Used Knowledge Base](README.md)

**Where:** Configuration > Fields Used > **Programs** (`/configuration/fieldsused/programs`)

Intro text: "Customize the fields used for programs. You can edit custom instructions for each field based on your use case."

- Start with **Would you like to add Programs to your source?**
- Hide program fields you do not use with **Show Item**.
- Add instructions for each field.
- Select **Save**.

## What it affects
The Program pages: General Information, Link and Image, Overview, Admissions, Quote Information, Filters, Related Links, List of Notes / FAQ, and others. See the Program documentation.

- **Filters**, **Related Links**, and **List of Notes / FAQ** can be turned off here. Their editing pages then link back to this page.
- Instructions you enter for these appear under an **Instructions** heading on those pages.

If Programs are off, the Programs page says "Your area does not use programs."

See [How Fields Used Works](01-how-fields-used-works.md) for the controls.
