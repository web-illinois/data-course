# Fields Used: Courses

[Back to Fields Used Knowledge Base](README.md)

**Where:** Configuration > Fields Used > **Courses** (`/configuration/fieldsused/courses`)

Intro text: "Customize the fields used for courses. You can edit custom instructions for each field based on your use case."

- Start with **Would you like to add courses to your source?**
- Hide course fields you do not use with **Show Item**.
- Add instructions for each field.
- Select **Save**.

## What it affects
The Course pages: General Information, Link and Image, Overview, Admissions, Quote Information, Filters, Related Links, List of Notes / FAQ, Faculty, and others.

- **Filters**, **Related Links**, and **List of Notes / FAQ** can be turned off here.
- Courses must be on to connect requirement sets to courses, to use sections, and to import courses.

If courses are off, the Courses page says "Your area does not use courses."

See [How Fields Used Works](01-how-fields-used-works.md) for the controls.
