# Fields Used: Requirement Sets

[Back to Fields Used Knowledge Base](README.md)

**Where:** Configuration > Fields Used > **Requirement Sets** (`/configuration/fieldsused/requirementsets`)

Intro text: "Customize the fields used for requirement sets. Note that you need to have credentials enabled to use requirement sets effectively. You can edit custom instructions for each field based on your use case."

- Start with **Would you like to add requirement sets to your source?**
- Hide requirement set fields you do not use with **Show Item**.
- Add instructions for each field.
- Select **Save**.

## What it affects
The Requirement Set pages (General Information, Courses, Technical Information) and the Requirement Sets list.

- Enable **credentials** so requirement sets can be used by a credential.
- Enable **courses** to connect requirement sets to courses.

If requirement sets are off, the Requirement Sets page says "Your area does not use requirement sets."

See [How Fields Used Works](01-how-fields-used-works.md) for the controls.
