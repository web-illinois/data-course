# General Information

[Back to Courses Knowledge Base](README.md)

**Where:** Course sidebar > **General Information** (`/course/general`)

| Field | What to enter |
|-------|---------------|
| **Title** | The course name. |
| **Rubric** | The subject code (for example, a department abbreviation). |
| **Course Number** | The course number. |
| **Platform Type** | Where the course is offered (for example, campus or an online platform). |
| **Summary Title** | Heading used in lists and search results. |
| **Summary Text** | Short description for lists. |
| **Contact** | Contact person. |
| **Contact Email** | Contact's email. |
| **Description** | Course description. |
| **Information** | Additional information. |
| **Course Length** | Expected length. |
| **Course Cost** | Cost. |
| **Credit Hours** | Credit hours. |
| **Enrollment Date** | When students can enroll. |

Select **Save**, then **View Course** to check the result. Fields your source has hidden do not appear.

> Imported courses may be overwritten by later imports. See the import articles.
