# Related Links

[Back to Courses Knowledge Base](README.md)

**Where:** Course sidebar > **Related Links** (`/course/relatedlinks`)

Build a list of related links displayed on the course page.

1. Add links (text and web address) with the link list editor.
2. Remove or reorder as needed.
3. Select **Save**.

Instructions from your administrator appear under **Instructions**. If the page says Related Links are not used, enable them in **Configuration > Fields Used > Courses**.
