# Faculty

[Back to Courses Knowledge Base](README.md)

**Where:** Course sidebar > **Faculty** (`/course/faculty`)

## Faculty List
Each existing faculty member shows:
- **Name**
- **Net ID**
- **Profile URL**
- **Show In Profile?** switch
- **Remove** button

Edit the values directly or select **Remove** to delete the entry.

## Add / Edit Faculty
1. Enter **Name**, **Net ID**, **Profile URL**, and set **Show In Profile?**.
2. Select **Add**.
3. Select **Save** to store all changes.

A **Back** button appears when you arrived from a quick link.
