# List of Notes / FAQ

[Back to Courses Knowledge Base](README.md)

**Where:** Course sidebar > **List of Notes / FAQ** (`/course/notelist`)

Generates an FAQ-like area or individual notes displayed on the course page.

1. Add notes with the note list editor.
2. Reorder or remove as needed.
3. Select **Save**.

Instructions from your administrator appear under **Instructions**. If notes are not used, enable them in **Configuration > Fields Used > Courses**.
