# Link and Image

[Back to Courses Knowledge Base](README.md)

**Where:** Course sidebar > **Link and Image** (`/course/link`)

| Field | What to enter |
|-------|---------------|
| **URL Fragment** | The part of the web address that identifies the course. |
| **Summary Link (URL)** | Link used from summaries and lists. |
| **Apply Now / Get More Information Link (URL)** | Link to apply or learn more. |
| **Image URL** | Image shown in lists. |
| **Image Alt Text** | Description of the image for screen readers. |
| **Detail Course Image** | Larger image for the course page. |
| **Detail Course Image Alternative Text** | Description of the detail image. |
| **Video URL** | Optional video link. |

Select **Save** when done. Always provide alt text for images. Changing the URL Fragment may break existing links.
