# Section List

[Back to Courses Knowledge Base](README.md)

**Where:** Course sidebar > **Section List** (`/course/sectionlist`)

A section is an individual term-based class. A course must have at least one.

## Edit a section
1. In **Select a Section**, choose a section.
2. Select **Edit Section**.

## Create a section
Under **Create a New Section**, select **Create Section**.

If your area does not use sections, the page says so; enable them in the Configuration section.
