# Overview

[Back to Courses Knowledge Base](README.md)

**Where:** Course sidebar > **Overview** (`/course/overview`)

| Field | What to enter |
|-------|---------------|
| **Details** | Main course details. |
| **External Details** | Details drawn from or shown for external sources. |
| **Job Type Information** | Types of jobs related to the course. |
| **Professional Information** | Licensure, accreditation, and similar details. |
| **Skills** | Skills students gain. |

Select **Save**, then **View Course** to confirm.
