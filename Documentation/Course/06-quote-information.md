# Quote Information

[Back to Courses Knowledge Base](README.md)

**Where:** Course sidebar > **Quote Information** (`/course/quote`)

| Field | What to enter |
|-------|---------------|
| **Quote Title** | Heading for the quote. |
| **Quote Subtitle** | Who said it. |
| **Quote** | The quote text. |
| **Quote Image** | Photo of the person. |
| **Quote Image Alternative Text** | Description of the photo. |

Select **Save**. Get permission before publishing a person's name and photo.
