# Finding and Creating Courses

[Back to Courses Knowledge Base](README.md)

**Where:** **Courses** (`/courses`)

1. Search for a course using the search controls. A message ("Fetching courses, please be patient") appears while results load.
2. Select a course to edit it. Its **General Information** page opens.

## Creating a course
Under **Create a new course**, select **Create Course**. The button is disabled for restricted users. Enter details and select **Save**, then add at least one section from [Section List](12-section-list.md).

## Unavailable
"Your area does not use courses" means courses are off. Enable them in the Configuration section.

## Other ways to add courses
See [Import a Course](16-import-course.md) and [Import Canvas / Coursera Courses](17-import-canvas-coursera.md).
