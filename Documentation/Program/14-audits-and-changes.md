# Audits and Changes

[Back to Programs Knowledge Base](README.md)

**Where:** Program sidebar > **Audits and Changes** (`/program/audit`)

Shows a history of manual changes made to this program.

## Table columns
| Column | Meaning |
|--------|---------|
| **Date Changed** | When the change was saved. |
| **Net ID** | Who made it. |
| **Field Type** | Which page was changed (for example, Technical or Filters). |
| **Raw Data** | Select **Notes** to expand additional details about the change. |

## Limitations
- Only changes made manually in the application are recorded.
- Loading JSON files and updates through the API are **not** included.
- For details on exactly what changed, contact IT Partners @ Education.

## Related reports
Source-wide change lists are in the Audit area, such as **Recently Changed Items** (`/audit/changed`).
