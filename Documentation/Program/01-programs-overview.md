# Programs Overview

[Back to Programs Knowledge Base](README.md)

## What is a program?
A **program** is a group of credentials connected by a common educational thread. For example, a Learning Design and Leadership program may include a Bachelor's Degree, a Master's Degree, and a Doctorate Degree.

- A valid program must contain **one or more credentials**. It may contain only one.
- A **credential** is an individual certificate, endorsement, or degree. See the Credentials documentation for details.
- Program information is used for external marketing and websites. It does not replace a student requirement checklist (such as DARS).

## Before you begin
- Programs must be enabled for your source. If they are not, the Programs page says "Your area does not use programs" and links to **Configuration > Fields Used > Programs**.
- You must have edit access. Users who are restricted can only work with programs they were assigned (see [Security](13-security.md)).
- Choose a source on the home page before editing.

## Saving your work
- Most pages have an orange **Save** button. A message ("Program saved successfully.") confirms the save.
- Changes are **not** stored until you select **Save**. Save before moving to another page.
- The **Security** page is the exception: its changes apply immediately.
- The **View Program** link opens the published program page so you can check your work.

## Hidden and customized fields
Your source administrator can hide fields or add instructions for them in **Configuration > Fields Used > Programs**. If a field described here does not appear, it has been turned off for your source. Required fields cannot be turned off.
