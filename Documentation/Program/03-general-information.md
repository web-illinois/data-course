# General Information

[Back to Programs Knowledge Base](README.md)

**Where:** Program sidebar > **General Information** (`/program/general`)

This is the first page that opens when you select or create a program.

## Fields
| Field | What to enter |
|-------|---------------|
| **Title** | The program's full name. |
| **Summary Title** | A heading for the program in lists and search results. |
| **Summary Text** | A short description for lists and search results. |
| **Contact** | Name of the person who can answer questions. |
| **Contact Email** | Email address for that contact. |

## Steps
1. Fill in the fields.
2. Select **Save**.
3. Select **View Program** to see the published result.

## Tips
- Use the Summary fields for short, scannable text. Put longer content in [Overview](05-overview.md).
- A new program needs a title before it is useful. Save once to create it, then continue to the other pages.
