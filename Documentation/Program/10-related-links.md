# Related Links

[Back to Programs Knowledge Base](README.md)

**Where:** Program sidebar > **Related Links** (`/program/relatedlinks`)

Use this page to build a list of helpful links. They appear on the program page.

## Steps
1. Add links using the link list editor, entering the link text and web address for each.
2. Remove or reorder links as needed.
3. Select **Save**.

If your source administrator added instructions for this page, they appear under **Instructions**.

## When the page is unavailable
"Related Links are not currently being used for this source" means the feature is off. Enable it in **Configuration > Fields Used > Programs**.

## Tips
- Use descriptive link text such as "Apply to the program" rather than "click here".
- Check links periodically to make sure they still work.
