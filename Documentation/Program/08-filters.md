# Filters and Filter List

[Back to Programs Knowledge Base](README.md)

Filters let website visitors search for programs by department, skill, length, and tag.

There are two versions of this page. Which one you see depends on whether your source uses credentials.

| Your source | Menu item | Page type |
|-------------|-----------|-----------|
| Does **not** use credentials | **Filters** (`/program/filters`) | Editable |
| **Uses** credentials | **Filter List** (`/program/filtersread`) | Read only |

## Editable Filters page
**Where:** Program sidebar > **Filters**

Toggle each filter on or off for this program. Filters are grouped:

| Group | Meaning |
|-------|---------|
| **Departments** | Academic units inside your area, such as Astronomy, Electrical Engineering, or Linguistics. They may be official units or informal categories. |
| **Skills/Topics** | What a student expects to gain. These should be student-focused and may span departments (for example, Financial Management). |
| **Lengths** | Expected time to complete the credential, from a few weeks to several years. If a program has several options, select all that apply. |
| **Tags** | Defined by your college or department, such as self-paced degrees or certifications. |

Steps:
1. Toggle the filters that apply.
2. Select **Save**.

If your source administrator added instructions for this page, they appear under **Instructions**.

## Filter List (read only)
**Where:** Program sidebar > **Filter List**

When credentials are in use, a program's filters are **compiled from its credentials' filters**. You cannot change them here. The page lists each department, skill, length, and tag as **enabled** (bold) or **disabled**.

To change them, go to [Credential List](09-credential-list.md), open a credential, and edit its **Filters**.

## If you see a message instead of filters
- **"No filters are available for this source"**: nobody has created filters yet. A source administrator can add them in **Configuration > Manage Filters**.
- **"Filters are not currently being used for this source"**: filters are turned off. Enable them in **Configuration > Fields Used > Programs**.
