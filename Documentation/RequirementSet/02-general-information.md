# General Information

[Back to Requirement Sets Knowledge Base](README.md)

**Where:** Requirement Set sidebar > **General Information** (`/requirementset/general`)

| Field | What to enter |
|-------|---------------|
| **Title** | The name shown publicly, for example "Core Courses" or "Choose One Elective". |
| **Internal Title** | Optional. Extra text to tell similar sets apart in editor lists. It appears as `Title (Internal Title)`. It is not meant for public display. |
| **Description** | Explains the rule to students, for example "Complete all of the following courses." |
| **Minimum Credit Hours** | The fewest credit hours that satisfy this set. |
| **Maximum Credit Hours** | The most credit hours that apply to this set. |

Select **Save** when finished.

A Requirement Set is a group of courses that need to be taken in order to get a credential. It can be "take all of these courses" or "take 12 hours of some of these courses." Add this text manually in the **Description** field.

## Expressing the rule
A requirement set rule is typically one of:

| Rule | How to set it up |
|------|------------------|
| **Must take all of these courses** | Add every required course. Describe the rule in the **Description**. |
| **Must take one of these courses** | Add the choices and describe "choose one" in the **Description**. |
| **Must take 9 credit hours from the following courses** | Add the eligible courses, enter the credit hours in **Minimum Credit Hours** (and **Maximum Credit Hours** if there is a cap), and describe the rule in the **Description**. |

> This page has no separate rule selector. The rule is conveyed through the description and the credit hour fields. Confirm with your administrator how rules are displayed on your site.

## Tips
- Use clear titles. Students see them in the plan of study.
- Use **Internal Title** to distinguish sets such as "Electives (Fall 2025)" and "Electives (Fall 2026)".
