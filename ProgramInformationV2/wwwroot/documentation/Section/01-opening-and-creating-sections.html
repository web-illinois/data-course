Opening and Creating Sections

Back to Sections Knowledge Base

Sections are managed from their parent course.

  1. Open the course (see the Course documentation) and choose Section List in the sidebar.
  2. To edit a section, choose it in Select a Section and select Edit Section.
  3. To add one, select Create Section under Create a New Section. The new section opens on its General Information page, linked to the course.

Sections can also be loaded by course import, which may overwrite existing information.

To leave a section, use Back to return to the course's Section List.
