End-user documentation for the Section pages of the Program Information application (pages under /section).

A section is an individual term-based class that belongs to a course. It may be synchronous or asynchronous, online or on-campus. A course must have at least one section.

# Article What it covers
1 Opening and Creating Sections How to reach section pages

4 Faculty Instructors
5 Technical Information URL fragment, IDs, delete

Basics

  • Section pages show a sidebar for the section. A Back button on each page returns you to the course's Section List.
  • Each page has an orange Save button. Changes are not stored until you select it. A message ("Section saved successfully.") confirms the save.
  • Your area must have sections enabled in the Configuration section.
