Basics

  • A course is a group of sections / classes that share a common body of knowledge. University courses have a rubric and course number; courses on platforms like Coursera may not.
  • A valid course must contain one or more sections. A section is an individual term-based class, synchronous or asynchronous, online or on-campus.
  • Most pages have an orange Save button. Changes are not stored until you select it. The Security page saves immediately.
  • View Course opens the published page.
  • Fields can be hidden or given instructions in Configuration > Fields Used > Courses.
  • If your area does not use courses or sections, pages show a message with a link to the Configuration section.
