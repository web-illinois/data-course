Import Canvas / Coursera Courses

Back to Courses Knowledge Base

Where: Courses > Import Canvas Courses (/courses/canvasimport) and Import Coursera Courses (/courses/courseraimport)

Importing overwrites any changes you made to an existing item.

Steps

  1. Select Search for Courses.
  2. Move courses to the import list with Add To Selected List or Add All. Use Remove From Selected List or Remove All to adjust.
  3. Select Import Courses.
