Courses By Requirement Sets

Back to Audit Reports Knowledge Base

Where: Audit > Courses By Requirement Sets (/audit/coursebyrequirementset). The page heading is List of Courses by Requirement Set.

Description: Lists each course with the requirement sets that contain it.

Column Meaning
Title The course, with its requirement sets listed below. Select a course or a requirement set to open it.
Is Active Whether the course is active on your site.

Use this report to see the effect of changing or deleting a course: every requirement set listed under it is affected.
