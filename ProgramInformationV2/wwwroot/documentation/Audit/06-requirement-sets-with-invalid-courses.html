Requirement Sets with Invalid Courses

Back to Audit Reports Knowledge Base

Where: Audit > Requirement Sets with Invalid Courses (/audit/requirementsetswithinvalidcourses)

Description: Lists requirement sets that contain one or more courses the system considers invalid, so they can be fixed.

Column Meaning
Title The requirement set. Select it to open its Courses page.
Is Active Whether the set is active on your site.

What to do

Open the set and review its courses. Remove or replace any course that no longer exists or should not be listed, then select Save.
