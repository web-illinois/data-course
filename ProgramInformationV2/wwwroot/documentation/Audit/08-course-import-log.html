Course Import Log

Back to Audit Reports Knowledge Base

Where: Audit > Course Import Log (/audit/courseimportlog)

Description: Shows the status of course imports, including which are pending, completed, or not found.

See also Import a Course.

Filter the log

  • Rubric: enter a rubric to limit the log.
  • Import Type: All Items, Pending, Completed, or Not Found.
  • Select Search.

Summary lines

  • Last Import on date: when an import last ran.
  • Number of Items pending: the total across all sources, not just yours.

Table

Column Meaning
Date Submitted When the import was requested.
Date Imported When it ran, or Pending if it has not run yet.
Course The rubric and course number.
Log Messages about the import.

Remove Logs

Remove Logs clears the import log entries for your source. Use it to clean up after imports finish.
