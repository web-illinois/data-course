Link and Image

Back to Programs Knowledge Base

Where: Program sidebar > Link and Image (/program/link)

Fields

Field What to enter
URL Fragment The part of the web address that identifies this program (for example, learning-design).
Link URL The main web address for the program.
Alternate Link URL A second link, such as an application or information page.
Alternate Link Text The words shown for the alternate link.
Program Image The image used when the program appears in lists.
Program Image Alternative Text A description of the image for screen readers.
Detail Program Image The larger image used on the program's own page.
Detail Program Image Alternative Text A description of the detail image.
Video URL Optional link to a video about the program.

Steps

  1. Enter the links.
  2. Use the image controls to choose or upload each image.
  3. Enter alternative text for every image.
  4. Select Save.

Tips

  • Always enter alternative text. It makes the page accessible and is read aloud by screen readers.
  • Changing the URL Fragment can change the program's address. Links that used the old address may stop working.
