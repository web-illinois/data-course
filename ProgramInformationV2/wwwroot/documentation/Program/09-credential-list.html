Credential List

Back to Programs Knowledge Base

Where: Program sidebar > Credential List (/program/credentiallist)

This page appears only when your source uses credentials. A program must contain at least one credential, and this is where you open or create them.

Opening a credential

  1. In Select a Credential, choose a credential. Each entry shows the credential type followed by its title (or the program title if the credential has no title of its own).
  2. Select Edit Credential. The credential's General Information page opens.

Creating a credential

  1. Under Create a New Credential, select Create Credential.
  2. The credential's General Information page opens, linked to this program.
  3. Enter the details and select Save there.

Notes

  • If your source does not use credentials, the page says so and links to the Configuration section.
  • Program filters are built from credentials. See Filters and Filter List.
  • Moving a credential to another program is done from the credential's Technical Information page. Moving a program's only credential removes that program.
