List of Notes / FAQ

Back to Programs Knowledge Base

Where: Program sidebar > List of Notes / FAQ (/program/notelist)

Notes are FAQ-style entries. Each has a heading or question, a text area, and a link that can send the reader to more information. They appear on the program page.

Steps

  1. Add a note and fill in its heading, text, link text, and link URL.
  2. Reorder or remove notes as needed.
  3. Select Save ("Once everything looks good, click the save button to apply your changes").

If your source administrator added instructions, they appear under Instructions.

Note templates

Source administrators can create note templates in Configuration > Note Templates that apply to many programs, credentials, or courses.

  • A template can be limited by Department, Degree, Format, Skill, or Tag, so it only applies to matching programs.
  • To override a template on one program, add a note with the same title as the template.
  • Notes written on a program appear at the end of the list, unless they override a template.
  • To control where an override appears, create a placeholder note with a blank description, link text, and link URL. Notes with all three blank are never displayed.

When the page is unavailable

"Notes are not currently being used for this source" means the feature is off. Enable it in Configuration > Fields Used > Programs.
