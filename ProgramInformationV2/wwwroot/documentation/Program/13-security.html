Security

Back to Programs Knowledge Base

Where: Program sidebar > Security (/program/security)

Use this page to control which restricted users can edit this program.

Background

Users of a source are either:

  • Unrestricted: can edit everything in the source.
  • Restricted: can edit only the programs and credentials assigned to them.

Source owners set a user's restriction on Configuration > Security. This page assigns a program to those restricted users.

Using the page

The page lists every restricted user of the source by email. For each user, a switch shows:

  • Can Edit: the user can edit this program.
  • Cannot Edit: the user cannot.

Flip the switch to change access.

Changes apply immediately. There is no Save button on this page.

What restricted users see

  • The Programs list shows only programs they can edit.
  • The Create Program button is disabled.
  • The Configuration > Security page is unavailable to them.

If the list is empty

No users in your source are currently restricted. Restrict a user on Configuration > Security, and they will appear here.
