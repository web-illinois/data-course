Quote Information

Back to Programs Knowledge Base

Where: Program sidebar > Quote Information (/program/quote)

Use this page to feature a testimonial from a student, alum, or faculty member.

Fields

Field What to enter
Quote Title A heading for the quote.
Quote Subtitle Who said it (name, role, graduation year).
Quote The text of the quote.
Quote Image A photo of the person.
Quote Image Alternative Text A description of the photo for screen readers.

Steps

  1. Fill in the fields and add the image.
  2. Select Save.
  3. Select View Program to confirm.

Tips

  • Get permission before publishing a person's name and photo.
  • Fill in alternative text whenever you add an image.
