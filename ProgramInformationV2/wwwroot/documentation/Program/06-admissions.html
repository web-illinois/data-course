Admissions

Back to Programs Knowledge Base

Where: Program sidebar > Admissions (/program/admissions)

All fields use a rich text editor.

Fields

Field What to enter
Admission Requirements What applicants need to be admitted (for example, GPA, test scores, prerequisites).
Transfer Student Requirements Extra or different requirements for transfer students.
Program Tracks Descriptions of tracks, concentrations, or options within the program.

Steps

  1. Enter text in each editor.
  2. Select Save.
  3. Select View Program to check the result.

Tips

  • Link to your official admissions page for details that change often.
  • Credentials also have their own Admissions page. Use the program page for information that applies to every credential in the program.
