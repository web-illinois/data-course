Overview

Where: Program sidebar > Overview (/program/overview)

All fields on this page use a rich text editor, so you can format text with headings, lists, and links.

Fields

Field What to enter
Description A full description of the program.
Who Should Apply The type of student the program is intended for.
Job Type Information Types of jobs graduates can pursue.
Professional Information Licensure, accreditation, or professional development information.
Skills Skills students gain.

Steps

  1. Enter text in each editor.
  2. Select Save.
  3. Select View Program to confirm the formatting.

Tips

  • Paste plain text if formatting from another document looks wrong, then format it in the editor.
  • Keep skills student-focused. The same idea applies to skill filters in Filters and Filter List.
