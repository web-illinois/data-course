Fields Used: Credentials

Back to Fields Used Knowledge Base

Where: Configuration > Fields Used > Credentials (/configuration/fieldsused/credentials)

Intro text: "Customize the fields used for credentials. You can edit custom instructions for each field based on your use case."

  • Start with Would you like to add credentials to your source?
  • Hide credential fields you do not use with Show Item.
  • Add instructions for each field.
  • Select Save.

What it affects

The Credential pages: General Information, Link and Image, Overview, Admissions, Quote Information, Filters, Related Links, List of Notes / FAQ, Course List, Transcript Information, and others.

  • Filters, Related Links, and List of Notes / FAQ can be turned off here.
  • Credentials are needed to use requirement sets effectively.
  • If credentials are off, a program's Credential List page says so and links here. A program's Filters page becomes editable instead of read only.

See How Fields Used Works for the controls.
