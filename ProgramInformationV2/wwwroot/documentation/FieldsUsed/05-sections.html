Fields Used: Sections

Back to Fields Used Knowledge Base

Where: Configuration > Fields Used > Sections (/configuration/fieldsused/sections)

Intro text: "Customize the fields used for sections. Note that you need to have courses enabled to use sections appropriately, and sections are usually used in conjunction with Electronic Data Warehouse banner data. You can edit custom instructions for each field based on your use case."

  • Start with Would you like to add sections to your source?
  • Hide section fields you do not use with Show Item.
  • Add instructions for each field.
  • Select Save.

What it affects

The Section pages (General Information, Location & Time, Faculty, Technical Information) and a course's Section List.

  • Enable courses first.
  • Course import from the Electronic Data Warehouse requires both courses and sections.

If sections are off, a course's Section List says "Your area does not use sections."

See How Fields Used Works for the controls.
