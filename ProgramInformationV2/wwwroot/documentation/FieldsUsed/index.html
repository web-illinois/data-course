End-user documentation for the Fields Used pages of the Program Information application (pages under /configuration/fieldsused).

Fields Used pages customize the editing screens for your source. A source is a separate workspace for a college, department, or unit, with its own data, filters, settings, and security.

Fields Used settings apply only to the source you are working in. Changing them does not affect any other source.

On every Fields Used page you can:

  1. Turn a feature on or off (for example, programs or sections).
  2. Hide fields that you do not use.
  3. Add instructions for each item, shown to editors on the matching field.
