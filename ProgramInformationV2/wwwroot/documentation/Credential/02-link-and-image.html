Link and Image

Back to Credentials Knowledge Base

Where: Credential sidebar > Link and Image (/credential/link)

Fields

Field What to enter
URL Fragment The part of the web address that identifies the credential.
Summary Link (URL) Link used from summaries and lists.
Apply Now / Get More Information Link (URL) Link for applying or learning more.
Credential Image Image shown in lists.
Credential Image Alt Text Description of that image for screen readers.
Detail Credential Image Larger image for the credential page.
Detail Credential Image Alt Text Description of the detail image.

Steps

  1. Enter links and choose images with the image controls.
  2. Enter alt text for each image.
  3. Select Save.

Changing the URL Fragment may change the credential's address and break existing links.
