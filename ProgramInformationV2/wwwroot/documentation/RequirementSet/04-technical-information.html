Where: Requirement Set sidebar > Technical Information (/requirementset/technical)

Status on Site

Controls whether the requirement set is active on your site. Select Save after changing it.

Credentials using this Requirement Set

Lists every credential that uses the set.

Is This Shared?

Controls whether other credentials may reuse the set.

  • The toggle is available only when exactly one credential uses the set.
  • If more than one credential uses it, the page says "Requirement Sets must be used by one and only one credential before making it private."

Information to Copy

  • Id: the set's unique ID.
  • Edit Link: direct link to edit it.

Delete

  • A set that no credential uses shows a delete notice. Deleting cannot be undone.
  • "Requirement Sets used by a credential cannot be deleted." Remove it from each credential's Course List first.
