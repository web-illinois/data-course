Finding and Creating Requirement Sets

Where: Requirement Sets (/requirementsets)

Finding a requirement set

  1. Wait for "Fetching requirement sets, please be patient." to finish.
  2. Search for a requirement set and select it to edit. Its General Information page opens.

Creating a requirement set

Under Create a new requirement set, select Create Requirement Set, then complete General Information and Courses.

A requirement set only appears to students when a credential uses it. If credentials are not enabled, the page warns that new requirement sets cannot be used until credentials are enabled.

The easiest way to create a set for a specific credential is from the credential's Course List page, using Create New Requirement Set. See How Credentials, Requirement Sets, and Courses Work Together.

Unavailable

"Your area does not use requirement sets" means they are turned off. Enable them in Configuration > Fields Used > Requirement Sets.
