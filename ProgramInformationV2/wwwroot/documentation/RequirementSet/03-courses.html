Courses

Back to Requirement Sets Knowledge Base

Where: Requirement Set sidebar > Courses (/requirementset/courses)

A requirement set may contain courses (0 to many). Courses are sorted alphabetically automatically.

Courses already in the set

Each course shows:

  • The course title. Select it to edit the course.
  • Optional Public Notes: a short note shown with the course, to clarify details such as needing a specific section or special approval.
  • Remove: takes the course out of this set. This does not delete the course itself.

Add Courses

  1. Search for a course in Add Courses.
  2. Select Add to Requirement Set.
  3. If the course does not exist yet, select Create New Course.
  4. Select Save.

Use Back to return to where you came from (for example, the credential's Course List).

Requirements

Courses must be enabled in Configuration > Fields Used > Courses; otherwise the page says "To connect requirement sets to courses, courses must be enabled."
